Each stream of this extension supports a range of Quarkus versions.
Only maintained streams receive bug fixes and dependency updates.

|===
|Quarkus OpenFeature |Quarkus |Maintained

|2.0.x
|4.0+
|{maintained}

|1.0.x
|3.33+
|{maintained}
|===

[%hardbreaks]
{maintained} Actively developed and fully maintained, receives new features, bug fixes, dependency updates.
{legacy} Maintained in a legacy status, receives important bug fixes, but no new features.
{unmaintained} Not maintained, migration to a newer version is recommended.
